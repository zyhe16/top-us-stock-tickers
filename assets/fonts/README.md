# Landing-page fonts

The landing page uses the Latin WOFF2 builds of Inter and Space Grotesk. The API serves both files from `/assets/fonts`, so opening the page does not contact Google Fonts.

The source files came from the official [Google Fonts repository](https://github.com/google/fonts):

- [Inter](https://github.com/google/fonts/tree/main/ofl/inter)
- [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk)

Both fonts use the SIL Open Font License 1.1. Their license notices are stored beside the font files.
